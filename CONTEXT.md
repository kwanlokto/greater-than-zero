# Notch

A lifter's own training and food log, kept on their phone: Workouts repeated from History, Meals counted against Macro targets, and daily Weigh-ins.

## Language

**Category**:
A kind of Workout the lifter names, such as Push. A Workout has one or none, and a Rotation is an ordered cycle of them.
_Avoid_: Routine, template, type

**Repeat**:
To start a Workout from a finished one. The new Workout is an editable copy that keeps the Category and brings that day's Sets along as planned Sets.
_Avoid_: Copy, clone, template

**Planned set**:
A Set filled in ahead in a Workout in progress. It becomes a Set only when the lifter confirms it.
_Avoid_: Target, draft set

**Exercise entry**:
One Exercise as done in one Workout, holding the Sets logged for it. "Entry" on its own always means this.

**Backup file**:
All of a lifter's data as one file, exported from Settings and imported to replace everything on a phone. A file from an older version of Notch is brought up to date the way the phone itself would have been.
_Avoid_: Export (for the file)
