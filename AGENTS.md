## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues for `kwanlokto/greater-than-zero`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five default triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## User flows

Screen IDs (S01…, dialogs D01…) and diagrams of every way between screens are in `docs/user-flows.md`. Read it before working on or naming a screen, and update it in any change that adds, removes or reconnects a screen or dialog.
